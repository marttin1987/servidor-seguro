# 01 - Inventario inicial del laboratorio

## Entorno de virtualización

- **Hipervisor:** VirtualBox.
- **Sistema anfitrión:** Ubuntu.
- **Máquina virtual:** servidor-seguro.
- **Sistema operativo invitado:** Debian GNU/Linux 13.

## Red

- **Modo de red:** NAT.
- **Dirección IP de la VM:** 10.0.2.15/24.
- **Puerta de enlace:** 10.0.2.2.

## Servicios

- **Servidor web:** Nginx.
- **Acceso remoto:** SSH mediante clave pública configurada.
- **Firewall:** UFW activo.

## Estado inicial

El laboratorio permite practicar administración de sistemas Linux,
configuración de red, acceso remoto, firewall y publicación web.
